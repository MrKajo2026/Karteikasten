# Karteikasten

Vokabeltrainer mit Lernsets, Foto-Import von Buchseiten, Karteikarten, Multiple Choice, Schreiben und Wiederholung nach Fächern.

- `index.html` – die App (GitHub Pages)
- `supabase/setup.sql` – Tabelle und Zugriffsregeln
- `supabase/functions/scan/index.ts` – Fotoerkennung (in Supabase als Funktion `smart-service` deployt)
